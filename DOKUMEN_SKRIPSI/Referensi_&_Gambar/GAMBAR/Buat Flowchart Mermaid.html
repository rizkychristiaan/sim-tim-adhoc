Alur sistemnya

1. Login

  • Mulai → Halaman Login

  • User memasukkan email & password

  • Sistem melakukan validasi kredensial.

  • Jika salah → tampil pesan error → kembali ke halaman login.

  • Jika benar → sistem mengecek role akses.

2. Role Admin & Ketua Tim

  • Admin → Akses Admin

  • Ketua → Akses Ketua Tim

  • Keduanya masuk ke proses Kelola Tim Ad Hoc

  • Plotting anggota tim

  • Membuat penugasan/task

  • Sistem mengirim notifikasi dan pengingat deadline.

3. Role Anggota

  • Anggota → Akses Anggota

  • Melihat penugasan sendiri

  • Memperbarui status pengerjaan task

  • Mengunggah berkas LPJ/dokumen

  • Sistem memberikan notifikasi dan pengingat deadline.

4. Penyelesaian

  • Setelah proses notifikasi → Cetak Surat Tugas / SK dalam bentuk PDF

  • → SELESAI
